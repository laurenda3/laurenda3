## ⚡ Power Platform Projects

### 🧪 [Sealant Weight Check & Maintenance Alerts](https://github.com/laurenda3/power-platform-sealant-weight-check)
**Focus:** Quality data capture, tolerance checking, automated alerts

Model-driven Power App on Dataverse that replaces hand-calculated sealant and potting weights, plus a Power Automate flow that emails maintenance when a check fails.

▶️ [Watch the 70-second demo](https://youtu.be/uuLP_Nw_FGA)

**Highlights**
- Net weights and ratios calculate as you type, checked against limits that change by frame size
- Tolerances stored in a Dataverse table, so limits change without touching the app
- Dataverse-triggered cloud flow with an OData filter, so only failed checks start a run
- Alert email includes the line, shift, frame size, failed value, and limit

**Primary Skills:**  
Power Apps, Dataverse, Power Automate, Dataverse Triggers, OData Filters, Solutions
